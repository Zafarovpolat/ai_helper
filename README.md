# AI Helper — ИИ-аватар гид по истории Узбекистана

Веб-приложение с 3D-аватаром для музеев. Голосовой интерфейс, база знаний только по проверенным материалам.

## Структура

```
docs/
  technical.md  → ТЗ для исполнителей (техника, стек, сроки)
  client.md     → Документ для клиента (без техники, простым языком)
src/            → код приложения (Vite + React + Three.js)
public/         → статика, 3D модели (GLB)
assets/         → дизайн, референсы аватара
```

## Быстрый старт (для команды)

```bash
npm install
npm run dev
```
