# AI Helper — ИИ-аватар гид по истории Узбекистана

Веб-приложение с 3D-аватаром для музеев. Голосовой интерфейс, база знаний только по проверенным материалам.

## Структура

```
docs/
  technical.md  → ТЗ для исполнителей (техника, стек, сроки)
  client.md     → Документ для клиента (без техники, простым языком)
src/            → код приложения (Vite + React + Three.js)
public/         → статика, 3D модели (GLB)
assets/         → дизайн, референсы аватара
```

## Реализация (ветка `feature/variant-a`)

MVP **Варианта A — стилизованный рассказчик** (путь EASY). Работает офлайн, без внешних API.

Что уже есть:

- **3D-аватар** в национальном образе (чапан, тюбетейка, борода) — собран из примитивов в Three.js (без GLB), с анимацией: дыхание, моргание, кивки, липсинк рта при речи.
- **STT (слух)** — Web Speech API (русский/узбекский), с текстовым полем как fallback.
- **RAG-lite** — поиск по проверенной базе знаний (`src/data/knowledgeBase.js`), без генерации: аватар отвечает только готовым проверенным ответом, иначе вежливо признаёт, что материала нет. Никаких галлюцинаций.
- **TTS (голос)** — SpeechSynthesis, события управляют анимацией рта.
- **Kiosk-интерфейс** — полноэкранный, переключение RU/UZ, популярные вопросы, источник под каждым ответом.

Запуск:

```bash
npm install
npm run dev   # http://localhost:5173
```
