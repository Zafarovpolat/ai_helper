# ИИ-аватар — гид по истории Узбекистана
### Веб-приложение с 3D-аватаром, голосом и базой знаний

Веб-приложение для экранов музея в полноэкранном kiosk-режиме. Посетитель говорит голосом, аватар отвечает только по проверенной базе.

---

## 1. Архитектура

Один конвейер для любого аватара:

```
Микрофон → VAD → STT → RAG (поиск по базе) → LLM (только по контексту) → TTS + viseme → 3D (Three.js)
```

*   Потоковый: озвучка стартует с первых слов, пока LLM дописывает ответ.
*   Кэш частых вопросов, fallback при обрыве сети, обновление базы на сервере → на все экраны.
*   Если один этап пакетный — весь конвейер ждет. Поэтому классический Whisper API без надстройки не подходит.

---

## 2. 3D в браузере

Без Unreal Engine. Любая модель рендерится в браузере через WebGL.

| Параметр | WebGL (браузер) | Unreal + Pixel Streaming |
|---|---|---|
| Железо | Мини-ПК, интегрированная графика | Сервер с GPU, постоянный канал 5–15 Мбит/с |
| Задержка | 16–33 мс | 80–250 мс |
| Офлайн | Да | Нет |

**Стек:** `Three.js + React Three Fiber` / `Babylon.js`, `glTF 2.0 / GLB` + `Draco + KTX2`, `Mixamo Humanoid`, `52 ARKit + 15 Oculus Visemes`.

**Требования к GLB:** `1 unit = 1 м`, Hips в корне, Mixamo-имена, 15 visemes + 52 ARKit, PBR, <8 МБ после сжатия.

**Инструменты:** `Ready Player Me`, `Avaturn`, `TalkingHead.js` (MIT), `HeadTTS/HeadAudio`, `Mixamo`. `HeadTTS` — только EN.

## 3. Вариант A — Стилизованный

Рассказчик в национальной одежде. Оптимален для музея.

**A-Easy:**
*   Модель `Ready Player Me` → готовый GLB.
*   Рендер `TalkingHead.js`, голос `Piper` / `Azure`.
*   Срок: 5–10 дней.

**A-Pro:**
*   База RPM + доработка модели: костюм, орнамент, 2K текстуры.
*   Рендер `R3F + drei`.
*   Срок: 2–3 недели.

В обоих: `Idle` + `Talking`, эмоции `neutral/friendly`, `Draco/KTX2`.

---

## 4. Вариант B — Фотореализм

Историческая личность (Амир Темур, Улугбек). В вебе — всегда оптимизированный реализм `2M → 30–50k` полигонов.

**B-Easy:**
*   `Avaturn Photo → 3D` из 1 фото. 70–80% похожести — собирательный образ.
*   Срок: 1–2 недели.

**B-Pro:**
*   Скульпт `ZBrush/Blender` с историком, `4K PBR`, грум, ручной риг `52 ARKit + 15 visemes`.
*   Срок: 4–7 недель.

**Альтернатива без 3D:** `D-ID / HeyGen` — из фото → MP4. Быстро, но не 3D, подписка, нет офлайна. Для исторической личности 2D-портрет часто достовернее.

| Параметр | A | B-Easy | B-Pro |
|---|---|---|---|
| Полигоны | 12–20k | 18–30k | 30–50k |
| GLB | 3–7 МБ | 5–10 МБ | 8–20 МБ |
| Загрузка 4G | 1–2 сек | 1.5–3 сек | 2–4 сек |
| FPS на ТВ-боксе | 55–60 | 45–60 | 30–55 |

## 5. STT — как слышит

Whisper из коробки не потоковый.

| Решение | Поток | Узбекский |
|---|---|---|
| Web Speech API | Да | RU/EN — да, UZ — нет |
| Whisper API | Нет | Да, средне |
| gpt-4o-transcribe | Да | Да |
| Realtime Whisper | Да | Да |
| Deepgram Nova-3 | Да | Слабо |
| Azure Speech | Да | Есть (`uz-UZ`) |
| faster-whisper + Silero VAD | Чанки | Лучший офлайн для UZ |

**Решение:** гибрид. `Web Speech API` для русского (мгновенно) + `faster-whisper large-v3` или `Azure` для узбекского. Уверенность <60% → `Повторите` + текстовое поле.

## 6. TTS + Липсинк — как говорит

Нужно: `аудио + viseme` (форма рта).

| TTS | Viseme | RU / UZ |
|---|---|---|
| Piper (локально) | Через Rhubarb/wawa | RU — да, UZ — кастом |
| Azure Speech | Да (15) | RU — да, UZ — есть |
| ElevenLabs | Да | RU — да, UZ — слабо |
| HeadTTS (Kokoro) | Да | Только EN |

| Липсинк | Принцип | Зависит от языка |
|---|---|---|
| TalkingHead | Текст → фонемы | Да (только en/de/fr/fi/lt) |
| Azure visemes | Отдает таймкоды | Да |
| Rhubarb | Аудио → viseme | Нет |
| wawa-lipsync | `AnalyserNode` | Нет, язык-независим |

**Связка:** `Piper + wawa-lipsync → TalkingHead` (MVP) или `Azure → viseme → TalkingHead` (продакшен).

`HeadTTS` пока только EN. Для UZ — `Azure` или кастом `Piper` на `Common Voice uz`.

## 7. LLM + RAG — только по базе

1.  Сбор → нарезка 500–800 токенов → эмбеддинги `multilingual-e5 / BGE-M3` → `Qdrant / Supabase pgvector` → проверка историком.
2.  Запрос → векторный поиск (топ-5) → реранкер → 3 фрагмента в промпт `только по контексту` → поток токенов.
3.  Кэш топ-30 вопросов.

Защита: строгий промпт + пост-проверка цитат + логи вопросов без ответа.

**LLM:** `GPT-4o-mini / Claude / Gemini` или локальная `Qwen/Llama` для офлайна.  
**Векторная БД:** `Supabase pgvector` (для MVP) или `Qdrant` (для продакшена).

## 10. Узбекский и риски

| Задача | Статус | Решение | План Б |
|---|---|---|---|
| STT UZ | WER выше RU | `faster-whisper` + Azure | Текстовое поле |
| TTS UZ | Мало голосов | Azure UZ / кастом Piper | RU голос + UZ субтитры |
| LLM UZ | Понимает латиницу/кириллицу | Промпт `на языке вопроса` | — |

**Риски:** галлюцинации → RAG; шум → направленный микрофон + `push-to-talk`; слабый интернет → офлайн-кэш; тяжелая 3D → `Draco/KTX2` + тест на железе.

## 11. Рекомендация

**Старт — EASY + A (стилизованный).** За 3–5 недель — пилот, сбор реальных вопросов. Если зайдет — `PREMIUM B-Pro` для флагмана.

**Максимум (без ограничений):** `B-Pro + Azure + GPT-4o + Qdrant Cloud` — 2–3 мес., но и там 2 недели EASY-пилота перед скульптом.

*   Фото киоска и характеристики мини-ПК.

## Приложение

### ТЗ для 3D-моделлера

*   Формат `glTF 2.0 / GLB`, тело отдельно, анимации отдельно.
*   Полигоны `12–30k` (A) / `30–50k` (B-Pro), ретопология.
*   Текстуры `PBR 2K` (A) / `4K` (B-Pro), `KTX2`.
*   Риг `Humanoid 55–65`, Mixamo-имена.
*   Морфы `52 ARKit + 15 Oculus visemes`.
*   Масштаб `1 unit = 1 м`, Hips в центре, рост 1.75 м.
*   Оптимизация `<8 МБ` (A) / `<20 МБ` (B-Pro), `FPS >45`.

### Чек-лист приемки

| № | Проверка | Как проверить |
|---|---|---|
| 1 | GLB без ошибок | https://gltf.report |
| 2 | Морфы работают | `Morph Targets` |
| 3 | Mixamo-скелет | Залить `Idle.fbx` |
| 4 | PBR без пятен | `Three.js + HDRI` |
| 5 | Вес <10/20 МБ | `Draco/KTX2` |
| 6 | FPS >45 | `Chrome Performance` |
| 7 | 15 visemes | `Ассалому алайкум` |

### Глоссарий

| Термин | Значение |
|---|---|
| STT | Голос → текст |
| TTS | Текст → голос |
| Viseme | Форма рта для звука |
| Blendshape | Деформация лица (52 ARKit) |
| RAG | Поиск по базе + ответ только по найденному |
| GLB | Файл 3D-модели для веба |
| VAD | Детектор речи |
